# SkillFlow 补强实验计划

**Problem**：现有 P4 补证先导主要验证同一 predictor 的字段依赖，尚不能证明独立执行记录上的判断可靠性；成本没有统一计入初始证据，跨字段清理也没有完整登记。

**Method Thesis**：把“哪些记录足以支撑哪些机制判断”做成可执行、可审计的证据合同，在独立执行记录和冻结留出上测量错误确定性、覆盖与补证负载。框架是主线，动态补证只是可删除的应用。

**Date**：2026-09-19。**状态**：NOT_STARTED；本文件不是新增实验完成记录。

## 共用测量合同

1. **统计单位**：`execution_unit_id` 是独立初始化的一次逻辑任务实例；`family_id` 表示共享构造/任务模板；`source_id` 表示执行来源。一个任务多个 metric/query、干预分支、budget、mask 或 policy seed 都是重复测量。必须同时报 family、执行单元、query 和轨迹行数，不能宣称 48 个独立同分布任务。
2. **结果分开**：报告 point / bounded / unknown / not_applicable / error。未知和 N/A 不计正确；N/A 的资格判定单列与独立资格参照核对。Full 仅是同 predictor 完整观察比较器，不是真值。
3. **决定性指标**：错误确定性 `wrong_point / all_oracle_point_queries` 与选择性错误率 `wrong_point / answered_oracle_point_queries` 并列；正确确定覆盖 `correct_point / all_oracle_point_queries`；总体点覆盖、未知率、参照可用率。所有分母保留，不只展示“回答中 100% 正确”。错误点判断包括误报和漏报，另列错误安全结论。
4. **缺执行记录**：无 receipt 或无 side-effect 记录只说明缺证。只有独立完整监测明确证明未执行，才可作为“没有违规执行”的真值；未知不能计为安全、防御成功或任务失败。collector 崩溃、超时也不能证明未执行。
5. **配对统计**：同 unit/mask 的策略保持配对；先按 query 描述，再按 family 等权汇总。随机顺序/缺失的 3 个 seed 先在同 unit 内平均。族很少时主要报告逐族差异和范围；若给 cluster bootstrap 必须按 family 重采样并明确探索性，不给基于 query 数的独立 Bernoulli 区间。
6. **公平成本**：采用固定 canonical UTF-8 编码。登记原子证据 ID、唯一收费 owner channel、所有镜像位置和依赖；不得把恢复 provenance 时偷偷恢复 `counterfactual.source_object` 算成免费字段。所有策略使用同一 bundle 与相同初始观察。
7. **总负载**：`charged_total_bytes = initial_public_bundle_bytes + sum(actual_returned_bundle_bytes)`；对重传按实际付费字节收费，明确缓存策略；同时报告当前可见 JSON 大小、事件/字段数、family 数。控制/元数据按冻结规则统一计入或另列，绝不能只算新增字节而漏初始证据。一次请求的整个 bundle 不可超过剩余预算；只能在预先定义原子块后截取，不能运行后为某策略拆包。
8. **跨字段账本**：每个被删除/恢复位置必须有 dependency token 与 owner；物理重复传输字节均计费，逻辑去重只对确实无需再传输的缓存对象生效。未知 owner、无账本恢复或负增量截零掩盖实际成本都使该结果无效。
9. **策略可见信息**：metric/protocol、当前许可输入、当前预测状态、公开缺失 token、已获取通道以及统一的公开预算报价。禁止 Full、参照真值、隐藏文档、其他 query 结果、oracle 文件、隐藏执行状态。若报价本身可能泄漏缺失结果，应固定大小封包/填充，或声明该元数据可见并给所有策略相同信息，不能用隐藏 payload 的精确字节作为免费输入。
10. **恢复上限**：预算行表示“最多预算”，point 或已证明 N/A 的同一停止规则适用所有策略；终止状态重复到后续 budget 不增加样本。Full 不列为免费预算策略，不参与成本排名。

## Experiment Blocks

### B1 / M0：补齐证据依赖、投影和收费（MUST-RUN）

- **检验**：C1 的接口健全性和 C2 的公平比较前提。
- **数据**：只用旧 240/235 开发材料及新开发 fixtures。冻结 P4 仍只读；做版本化 wrapper，不覆盖历史 predictor。
- **实现**：建立 `dependency_contract.json`，包含 `metric/protocol -> evidence token -> concrete paths -> owner channel -> dependency closure`。重点补 provenance 清理嵌套 `counterfactual.source_object`、failure 清理 qualification/完整性字段、scope/lifetime 的跨字段副本。`missing_evidence` 不完整时明确返回不完整，不能声称解释完备。
- **验证**：9 通道的每个 mask 子集共 512 种，在小型开发 fixture 上枚举；检查顺序无关投影、重复投影幂等、全部遮蔽位置有 owner、恢复仅改变获准闭包、任意不可见值变更不改变许可输入/策略动作。泄漏测试修改 oracle、Full、标签和隐藏文档，冻结可见内容后策略输出必须不变。完整恢复在同版本合同内回到 Full；历史版本差异单列。
- **预算与结果**：0 新业务执行；基于固定字节账本测试初始负载、镜像字段、依赖恢复和超预算请求。复现 review 指出的 8+2 条 CI 轨迹差异，只验证跨字段依赖，不借此补齐 CI 因果真值。
- **成功门**：新定义接口中覆盖到的路径 100% 有 owner；0 未计费恢复、0 可见隔离反例、0 超预算接受。HIAA 13 项测试与已有分母修复保持通过。不能以改期望值掩盖语义改变。
- **失败解释**：门未过时停止效率/动态结论和留出预测；继续修开发材料、准备独立 runner 和记录器，不把整个项目停在等外部访问。
- **论文位置**：主文合同图/一个具体跨字段例子，附录 512-mask 检查及迁移差异表。这是前提，不单列算法贡献。

### B2 / M1：独立执行记录与独立参照（MUST-RUN）

- **检验**：C1 能否超出旧 predictor 的自验证。
- **来源优先级**：先检查本地已有 ClawTrojan/其他外部 harness 与可复用原始日志、依赖和许可；只有原始执行记录与权限边界可审计才接入。没有数据、依赖或网络权限时，记录 `external_source=NOT_AVAILABLE`，继续建立不 import SkillFlow 执行/判定模块的独立本地 sandbox runner。它只能称“独立代码路径与受控执行验证”，不能称跨平台外部真实 agent，也不能伪造模型行为。
- **动作与监测**：在新临时工作目录使用标准库文件写入、SQLite/KV 或本地事件队列模拟受限效果，不接触真实账号或外部服务。记录动作尝试与实际落地分别的 ID、原始文件/DB 前后摘要、单调时序、任务/会话边界。独立 supervisor 在动作边界记录执行事实；kill/中断场景须保留单独的完整性证据。
- **参照隔离**：oracle 直接从真实 side-effect、独立预注册 grant/revoke 时间表和任务产物要求计算；不调用 predictor、SkillFlow 的 oracle resolver、风险报表、task_success 布尔标签或 adapter 判定。oracle/Full 放独立目录，policy 子进程无读取权限；先运行完并封存所有策略轨迹，再 join 参照。adapter 只转换记录，不读取 oracle 结论。
- **参照范围**：UEA 和 TaskSuccess 必须有独立执行/产物参照。ALR/RIR 仅在实际完成合法 identity/neutral 对照、前缀一致/撤销边界证据和独立原因定义时评估；缺任一项保留未知并给出 coverage，不能把 scripted reason 当 LLM 内部原因。CI 只做依赖/资格检查，除非预注册并真正执行合格干预；不自动泛化为因果真值。
- **预注册任务**：总计 48 个新逻辑执行单元，12 个具名 family × 4 个实例。可用 4 个 UEA、4 个 TaskSuccess、2 个 ALR、2 个 RIR family；按 family 划 6 个开发、6 个留出，每类至少一族留出。设计覆盖授权未撤销/已撤销、跨 session 残留、动作尝试未落地、落地但回执丢失、产物错 hash/错绑定等相反情况；不得按成功或 predictor 可判性采样。
- **独立性边界**：每实例重新初始化资源和 grant IDs；同 family 仍相关。先写 `family_registry.json` 和 split，留出定义不能只是开发模板换 ID。所有分支、失败执行和重试合计最多 192 次实际 sandbox 执行，最多每逻辑单元 4 次；超限不自动扩容。执行前估计不足时裁剪非核心指标，不能用完成不足后补样本换出错任务。
- **对照**：独立 oracle vs Full 仅检查构念对应；带/不带关键证据的有限反事实观察检查不能代替真实执行。外部历史日志与 sandbox 分层报告，不混为一个数据源。
- **成功门**：每个确定真值都能追到 raw side-effect 和独立权限/任务要求；至少 UEA、TaskSuccess 两个合同通过。对来源、family、执行计数和缺失参照全量登记。若完整观测也错，先定位 adapter/语义，留出不用于调参。
- **失败解释**：仅 sandbox 可用则保留受控执行结论；若无法独立标注 ALR/RIR，它们只进入局限表。没有新外部来源时，不声称跨 harness 泛化。
- **论文位置**：主表按 source/metric 列完整观察正确性、参照覆盖及缺证状态；展示至少两条独立落地事实推翻表面日志直觉的可核查轨迹，若没有观察到则如实报告。

### B3 / M2：冻结 family 留出与同字节补证比较（MUST-RUN）

- **检验**：C1 的采集缺失边界，C2 的公平补证价值。
- **先冻结再看结果**：48 个单元的 family 划分、生成规则、所有 seed、adapter/oracle/predictor/ledger/policy hashes、预算和缺证机制写入 `PLAN.json` 与 SHA。旧 240+235 以及 24 个新开发单元可用于设计；24 个新留出单元的输出只能在最后评估一次。由同学/脚本封存留出最好；无法做到人隔离时至少进程隔离和访问日志，不谎称盲法。
- **三类缺证**：①整通道 collector 故障，按预定通道逐一移除及一个预定双通道组合；②不依赖结果的随机缺失（seed 19119/19120/19121，预定 1/3/5 通道缺失）；③失败相关压力条件，例如 supervisor 已记录效果但 collector 在 acknowledgment 前中断，优先丢 receipt/lifecycle。机制生成器可用实际故障事件，不能把事件或 oracle 标签传给 policy；它是预注册压力测试，不是估计现实缺失分布。
- **基线不超过三族**：A 通用顺序（固定全局顺序；3 个随机顺序作为同族方差参照）；B 强指标静态顺序（已有 PRIORITY、开发集 greedy 和按开发集字节收益的静态候选，预先限定最多 24 个候选/metric，只在开发集选一个并冻结）；C 依赖驱动动态（可选，见 B4）。每种 policy 同输入、同 bundle、同预算。Full 只作为完整观察上限，不是第四个零成本基线。
- **预算**：从开发集 canonical bundle 总负载的固定分位数和零点生成不超过 10 个全局绝对 byte 阈值，写入计划后不按留出结果重选。`B < initial_public_bundle_bytes` 时标记该 unit 在该预算不可行并公开共同分母；不能让不同策略用不同初始证据。全局阈值之外可补按任务 full-byte 比例的描述图，但不得代替公平绝对预算主表。
- **执行**：先跑静态基线；所有 mask/policy/seed 回放已封存记录，不重新执行业务动作。保留所有未知、N/A、错误和超时。策略代码只接触许可 bundle；未被采集字段的存在性也不能从错误信息、路径或缓存泄漏。
- **指标与图**：错误确定性/正确确定覆盖 vs charged total bytes 主图；family、字段/事件数为辅；按缺证机制和 family 报配对差异。预算 AUC 使用预注册公共 byte 区间。oracle 不足时另报 Full 一致性，不能替代正确性主图。
- **成功判断**：C1 的有限可靠性仅可写“在这些具名族与记录接口下未观察到错误确定性”，且必须给覆盖；不设用测试集筛选零错误子集。C2 只有 B 相对 A 在同字节留出上改善正确确定覆盖且不增加错误确定性，才可写有限条件下有补证价值；按族不一致要展示，族太少不喊显著。
- **失败解释**：若优势仅在 family 预算、不在字节预算，删除效率优势；若只开发集有效，删除迁移表述；若来自初始字节或跨字段免费恢复，作废该批效率结果并修开发协议。留出被用于修实现后必须改标开发，重新留出只能在当前 192 次上限内已有未触碰单元中完成，否则报告未完成，不扩容凑阳性。
- **论文位置**：主文一张公平预算图和一个逐族表；附录三类缺证完整结果和失败清单。

### B4 / M3：动态策略删除检验与贡献验收（动态 NICE-TO-HAVE；验收 MUST-RUN）

- **进入动态实验的门**：B1 的依赖/无泄漏/收费通过，强指标静态基线已冻结并在开发集验证；只允许在开发集提出一个依赖闭包驱动的最简动态策略。保留旧 top-level missing-field heuristic 阴性结果，不重命名为已验证新算法。
- **比较**：同预算、同输入、同停止规则比较 B 的最佳指标静态与一个冻结动态策略；不加新模型，不新增 sandbox 执行。动态若只根据 metric 选择固定表，应归类静态，不能靠命名宣称自适应。
- **主张判定**：动态在留出未优于静态，删除动态贡献并保留负结果；只有正确确定覆盖/字节 AUC 改善且错误确定性不变、逐族不是单一族驱动，才可作探索性应用结果。此 48 单元规模不自动支持顶会算法结论或显著性。
- **总验收**：输出 `CLAIM_EVIDENCE_MATRIX.md`，每主张标 SUPPORTED_IN_SCOPE / PARTIAL / UNSUPPORTED；明确证据来源层级、参照覆盖、未闭合 ALR/RIR/CI、外部 harness 是否缺席。至少一个来自真实受控执行/采集过程的非平凡发现，才考虑从实现审计提升为实证贡献；没有就如实保留为修复与框架验证，不扩大宣传。
- **图表与文字**：最多 2 张主表、1 张预算图、1 条案例流程；给可直接写入论文的通过/阴性/来源不足三套措辞。未测真实网络采集时延前只写“序列化负载代理”，不得写节省在线开销。
- **stop/go**：Go=有限独立参照+公平预算+冻结留出均成立；Partial=独立 sandbox 成立但外部来源缺席或语义覆盖窄；Stop 算法主张=动态无优势。Stop 不等于停止交付，所有情况均提交代码、冻结记录和负结果。

## Reproducibility and Delivery

本地 Codex 实现一个明确分阶段 CLI（以下是待实现接口，不是现有可直接运行命令）：`prepare -> check-contract -> collect-development -> freeze -> collect-heldout -> evaluate -> report`。`prepare/freeze` 输出不可变 JSON+SHA；`evaluate` 校验全部输入/代码哈希，不一致中止该次评估，要求新 run_id 而不是覆盖计划。

每个 run_id 必须保存：`PLAN.json`、`SOURCE_MANIFEST.json`、`FAMILY_SPLIT.json`、`DEPENDENCY_LEDGER.json`、`COST_LEDGER.jsonl`、隔离 raw 与 oracle 的目录、`PREDICTIONS.jsonl`、`QUERY_REGISTRY.csv`、`FAILURES.jsonl`、`SUMMARY.json`、`CLAIM_EVIDENCE_MATRIX.md`、`REPRODUCE.md` 和实际命令/环境版本。大结果可 gzip，记录压缩前后 SHA256。脚本每次至多处理500 query 的检查点，不能吞错误继续计成功。

最小回归包括 HIAA 已有13测试，以及真正针对依赖完整性、隐藏值不影响策略、oracle隔离、总字节计费和失败未执行语义的测试。不要把 implementation 的字段列表原样复制成期望值作为独立检验；不强求与本轮无关的全仓大实验。

## Risks and Mitigations

- **自证循环**：记录器、adapter、oracle、predictor职责分离；oracle不调用预测/既有风险判定；用真实产物检查而不是预置success布尔值。
- **数据来源夸大**：外部 archive、独立 sandbox、旧构造结果分别标注；没有 LLM 时不写真实 agent 泛化。
- **留出污染**：family级冻结，访问日志；修复接触留出后降为开发；不沿用“验证集”名称。
- **预算泄漏**：初始byte、镜像、跨字段引用、公开报价统一处理；无账本的证据不可用于结论。
- **少量族不稳定**：保留逐族表；错误和未知完整披露；不以query/seed数伪造统计功效。
- **语义缺口**：明确 missing proof 而不是借 oracle 填 predictor；范围不足时输出 PARTIAL。
