# P2 实时网页使用方式

## 访问

- 运行实验的 Windows 电脑：[本机页面](http://127.0.0.1:8765/)。127.0.0.1 指访问设备自身，不能在异地 iPad 上用它连接 Windows。
- 已授权异地访问：[临时只读页面](https://jvc-plots-outreach-justin.trycloudflare.com/)。用户进一步要求取消登录，目前无需密码；持有链接即可读取脱敏进度。
- 临时地址依赖 Windows 上的监控和隧道进程。服务退出或隧道更换后地址可能失效；本文件不保证归档后的持续可达性。

## 如何读数

正式阶段唯一分母为 39。执行结算包括技术异常，不能等同有效判分；有效判分只计原生 Safe、Partial、Compromised。TECH 单列，未知没有分数。请求上限是更紧的 4096 次预算尝试，已知未外发失败仍占预算。阶段补跑不新增唯一题目，原始失败在首次结果表保留。

页面约每 2 秒取一次状态。心跳来自运行器，不能用浏览器刷新时间判断实验是否活着。页面无控制按钮；刷新或断线不会触发重跑。检查进程时还应核对运行句柄和账本，不能仅依赖页面显示 RUNNING。

## 公开范围及验证

本地服务仅监听回环地址。异地入口只转发首页、固定静态资源和脱敏 status.json；它不是模型代理，也不开放目录或业务工具。已验证无需认证的首页及状态返回 200、非允许路径返回 404、POST 返回 405。取消登录的授权与验证记录见 protocol_revisions/PUBLIC_MONITOR_AUTHORIZATION.json。

公开进度包括模型名、任务 ID、角色、原生判分、阶段状态、请求计数及安全化错误码；不含提示、完整轨迹、认证凭据或私有推理。原始 provider 日志和访问认证历史文件不进入审查包。最终研究结论应以冻结的结果表和审查证据为准，运行中的网页不是最终论文统计。
