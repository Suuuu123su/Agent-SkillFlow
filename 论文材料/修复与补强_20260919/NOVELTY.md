### Vigil 完整性假设核对

已直接核对 v1 的三个位置：§III-C 明确完整采集假设，并将未暴露为工具调用的内部计算排除在视野之外；§IV-B 说明闭世界记录使“未出现”能够参与判定；§V-C 将判断等价建立在完整事实库上。该边界提供了研究不完整观察的动机，**不构成 Vigil 在自身假设内错误的证据**。

本文候选研究也不能擅自声称覆盖不可见的任意行为。必须先限定可接受的完整证据世界、观察接口及合同；若缺证来自未知的采集损坏，不能把未观察到的事件当成未发生。与 Vigil 的候选差异属于问题设定和测量证据，尚未证明新算法优势。

## 主方向：缺证可辨识性与证据恢复

**可核查的一句话差异：**固定机制合同与执行样本后，SkillFlow 显式保留与已见证据相容的相反结论，并研究哪些新增观察能够消除这种歧义，以及成本是多少。

这里“可辨识”应有明确定义。给定观察 O、合同 C 和预先限定的可接受完整世界集合 W(O)，只有所有相容世界在 C 下得到相同真值时才输出确定判断；否则输出未知。W(O) 的构造与范围必须披露。有限样本里的 Full 一致性不自动证明对所有相容世界都成立。

### 最小离线试验

1. **冻结样本与合同。**使用 HIAA 修复后的资格规则，固定 query universe 和运行簇。删除证据后不得重新筛选 cohort。优先 ALR、UEA、TaskSuccess、RIR 等下游机制判断，来源字段自身查询单列。
2. **制造可复现缺证。**分别采用随机字段丢失、整通道不可用、与失败相关的缺失机制。公开掩码与随机种子；相关缺失是人为压力条件，不能声称自然缺失分布已被估计。
3. **比较证据策略。**Full、基础日志、固定顺序恢复、随机恢复、合同导向恢复。在相同预算下比较。先以字段／事件数和序列化字节计成本；未测执行开销时不称线上节省。
4. **拆开两类参照。**历史记录用 Full 作为一致性参照；独立有限参照另报正确性。Full 仍未知的项目保持未知，不当成安全或正确标签。恢复来源必须是原有许可证据，不得读取隐藏标签或依据最终标签合成证据。
5. **加入同观察异真值见证。**在明确标记的受控合成世界中，构造可见调用相同但授权已撤销／未撤销、实际 Effect 落地／未落地等配对。核对删证据后观察完全相同、合同真值相反，补证据后才可区分。合成世界不得冒充真实 agent 运行。
6. **指标与独立性。**报告确定判断覆盖率、错误确定判断率、未知率、Full 一致率和恢复正确判断的成本；按机制和域拆分。记录独立运行／前缀／模板簇数，不能把同簇多查询当成独立任务。不得把删来源后自身来源判断消失计为主要价值。

若恢复策略利用当前可见值短路求值，可以作为实现方式；三值短路、特征选择和集合覆盖均不是新算法。枚举得到的“最小”只能限定为当前有限合同和已枚举证据通道下的结果。

### 反证与停止条件

- 合同导向策略在独立任务簇或域外留出上不优于固定顺序，或者统一字节预算后优势消失：保留负结果，不声称成本优势。
- 观察到的收益只来自自身字段查询、标签派生字段或 Full 答案泄漏：该结果无效，不能用于论文贡献。
- 所谓最小证据只是同一个 predictor 的读取字段集合，没有独立参照或合法的双世界见证：降级为实现分析。
- 无法定义合理的相容世界集合：仅报告有限数据上的证据消融一致性，不声称一般不可辨识边界。
- 实际数据全部为同一种真值／存在严重簇重复：不能从查询数量推断泛化能力，扩大之前先报告覆盖不足。

**可用论文措辞：**“在固定指标合同与许可观察接口下，我们评估机制判断的可辨识性，并通过受控缺证与恢复实验量化证据成本。”当前不能写“首个统一安全框架”“通用最小安全证据”“已验证线上防御收益”。

## 辅方向：合同与资格队列漂移审计

将其优先作为可信测量与可复现性支撑。HIAA 分母从 13 与 15 对齐而点值都为 1，本身不足以证明结论翻转，也不应把修复 bug 包装成新算法。

可实施的离线审计包括：HIAA 两套资格规则的逐四格对账；ALR 旧规则与严格合同的真／假／未知变化；RIR scheduled、formed-memory、confirmed-prefix 及最终成功筛选的漏斗。报告成员集合、分母差、点值差、未知／N/A 变化，并分离“固定合同换 cohort”与“固定共同 cohort 换合同”两个对照。不同估计对象不能直接解释为测量误差。

只有出现可迁移、非平凡、超出单处代码缺陷的发现，才考虑升级为单独实证贡献。若核心结论均不变、变化仅为定义不同，或影响局限于本仓库资格 bug，保持其工程审计定位。没有排名翻转就明确报告没有。

## 执行与结论边界

顺序为 HIAA 修复复算 → 合同对账 → 小规模缺证／恢复试验和双世界见证 → 通过反证检查后再扩大。以上候选试验可在不调用模型 API 的条件下完成；离线恢复不等于真实在线主动采集，离线机制测量不等于防御成功率提高。

本次查新没有确认任何一篇上述论文已完整包含该限定问题与拟议实验组合，也没有足够证据宣称无人做过。指定 helper 与跨模型审查仍未完成，投稿前需要补齐这两项，并继续核对相关工作最新版本。

## 补充基础文献核查（实验进行期间）

以下两篇已打开arXiv主页面并核对标题、作者与摘要；按本技能仍标记 `[UNVERIFIED: helper unavailable; primary arXiv page verified]`。

- Leucker等，2019，[Runtime Verification For Timed Event Streams With Partial Information](https://arxiv.org/abs/1907.07761)：用抽象事件流表示缺口内可能轨迹，并在不完整输入下给出可靠监测结果。本文不能把“未知保留／所有可能世界下安全判断”作为新的一般理论。
- Kallwies等，2022，[Symbolic Runtime Verification for Monitoring under Uncertainties and Assumptions](https://arxiv.org/abs/2207.05678)：对缺失或不精确观测使用符号公式，随新增观测迭代更新判定。本文不能把“补充信息后恢复判断”本身作为新机制。

由此进一步收窄候选贡献：针对Skill–Harness的具体证据合同，明确各机制的可观察边界、可复核的历史测量差异与补证成本，并展示通道之间的冗余／替代关系。是否足以形成顶会新贡献仍取决于非平凡实证发现；通用三值监测、不可区分世界论证和主动信息获取均有既有基础。
